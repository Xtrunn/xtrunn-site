# Xtrunn

Site vitrine statique de Xtrunn, publié avec GitHub Pages.

## Pages

- `index.html` présente Xtrunn et ses projets.
- `products/kleyris.html` présente Kleyris.
- `privacy.html` décrit les pratiques du site et de Kleyris.

## Publication

Dans les paramètres du dépôt, ouvrez **Pages**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/(root)`. L’adresse du site sera `https://xtrunn.github.io/xtrunn-site/`.

Avant de communiquer publiquement le site, remplacez ou vérifiez les liens de contact, les politiques et la disponibilité des boutiques dans les pages concernées.
