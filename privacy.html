Confidentialité

Dernière mise à jour : 16 novembre 2026

Qui publie Xtrunn et Kleyris

Xtrunn est le nom utilisé par l’éditeur indépendant de ce site et de Kleyris. Pour toute question relative à la confidentialité, utilisez le formulaire de contact du dépôt GitHub. Les messages et votre nom de compte peuvent être visibles publiquement si vous ouvrez une discussion publique.

Ce site

Ce site statique est hébergé par GitHub Pages. Xtrunn n’ajoute pas de publicité, de traceurs analytiques ni de formulaire de compte sur ce site. GitHub peut traiter des données techniques nécessaires à l’hébergement et à la sécurité du site selon sa propre politique de confidentialité.

Les couleurs que vous choisissez sont enregistrées dans le stockage local de votre navigateur et réutilisées lors de vos prochaines visites.

Données de Kleyris

Les clés API, fournisseurs, adresses e-mail associées, projets, liens de console, notes, dossiers et préférences sont enregistrés dans le stockage local du profil de navigateur. Kleyris ne transmet pas les clés API à Xtrunn ni aux fournisseurs d’IA. La protection par mot de passe chiffre les données concernées dans le profil. Une sauvegarde JSON ordinaire contient les clés en clair. Une sauvegarde chiffrée est chiffrée localement avec le mot de passe choisi par l’utilisateur.

Achats Pro

Pour acheter ou restaurer Kleyris Pro, l’utilisateur est redirigé vers ExtensionPay. ExtensionPay et Stripe traitent les informations nécessaires au paiement et au statut d’achat selon leurs politiques respectives. Xtrunn ne reçoit pas le numéro complet de carte bancaire. Consultez les politiques de confidentialité d’ExtensionPay et de Stripe.

Transfert entre navigateurs

Chaque navigateur conserve son propre stockage. L’utilisateur peut exporter une sauvegarde et l’importer dans un autre navigateur. Xtrunn n’héberge pas ces sauvegardes.

Suppression et contact

Les données locales peuvent être supprimées dans l’extension ou avec le profil du navigateur. Pour contacter l’éditeur, utilisez le formulaire GitHub. Évitez d’y inclure une clé API, un mot de passe ou toute autre information secrète.
